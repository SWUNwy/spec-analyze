#21 · 创意生成

Framework Deep Dive

_SCAMPER_
=========

七种系统性创意策略：替换、组合、改编、修改、他用、删除、反转，确保思维不局限于常规路径。

[下载 Skill](skills/scamper.md)

01 它解决什么问题

创新不需要从零开始
---------

大多数突破性创新来自对已有事物的系统性改造，而非凭空发明。但在头脑风暴中，团队往往被最大声的人或最显而易见的想法所主导，思维卡在熟悉的路径上无法突破。

SCAMPER 提供一份由七个维度构成的思维清单，强迫团队从七个不同角度审视同一个产品或流程——每个字母代表一种提问方式，每种方式都能打开一扇原本不会被注意到的门。

它的价值不在于替你思考，而在于**确保你不会遗漏任何一个可能的创新角度**。当团队在「替换」这个视角下卡住了，可以立刻切换到「组合」，不让思维停滞变成会议僵局。

02 框架结构

七个创意视角
------

SCAMPER 的每个字母代表一种系统性的创意提问策略。选定一个你想要改进的现有产品或流程，依次用七个视角对它发问。

S

Substitute

替换

把材料、人、流程、规则换成别的会怎样？

Spotify 把购买音乐替换为订阅流媒体

C

Combine

组合

把两个或多个想法、功能、产品合并会产生什么？

iPhone 把手机、iPod 和互联网设备合三为一

A

Adapt

改编

参考其他行业或领域的解决方案来改造它？

Airbnb 把酒店的共享逻辑改编到闲置房间

M

Modify

修改/放大/缩小

改变形态、外观、大小、速度或感知会怎样？

Mini Cooper 把汽车极致缩小，成为城市文化符号

P

Put to other uses

他用

以全新方式使用现有产品或功能？

Instagram 把手机相机重新定位为社交媒体工具

E

Eliminate

删除

移除某个部分或步骤，看看会发生什么？

Uber 删除了现金支付和调度电话

R

Reverse

反转/重排

把顺序、方向、角色或假设逆转会怎样？

Netflix 把「去租碟」反转为「影片来找你」

SCAMPER 应用示例：重新审视随身听

03 适用场景

什么时候该用它？
--------

SCAMPER 在任何需要对已有事物进行系统性创新的场合都能发挥作用——从产品功能到内部流程，从竞品回应到商业模式重构。

🔧

产品改版工作坊

在现有产品的迭代讨论前，用 SCAMPER 系统地探索所有改进方向，防止团队只看到最熟悉的解法。

⚡

功能创新 Sprint

当需要在一周内产生大量新功能想法时，SCAMPER 确保每个视角都被覆盖，避免头脑风暴流于表面。

🎯

竞品威胁响应规划

面对竞争对手的新产品，用 SCAMPER 系统分析己方产品的差异化可能性，快速找到反击角度。

🔄

初创公司业务转型

当原有商业模式遭遇增长瓶颈，SCAMPER 帮助团队系统性地探索 Pivot 方向，而不是仅凭直觉转型。

⚙️

内部流程优化

把 SCAMPER 应用到现有业务流程上，识别可以替换、删除或重排的环节，提升效率。

🏆

黑客马拉松创意引导

在 Hackathon 开始阶段，用 SCAMPER 给参与者提供结构化的创意框架，防止团队在发散阶段浪费时间。

04 真实案例

Apple iPod (2001)  
重新发明随身听
---------------------------

2001 年，便携音乐播放器市场已存在超过 20 年——从索尼 Walkman 到 CD 随身听，再到早期 MP3 播放器。市场看起来已经成熟，没有多少创新空间。苹果的团队对「便携音乐播放器」这个已有产品进行了 SCAMPER 式的系统性审视。

结果不仅仅是一款更好的 MP3 播放器，而是一个彻底改变了音乐产业的平台生态。

05 使用建议

让 SCAMPER 真正有效的五个关键
-------------------

SCAMPER 看起来只是一个提问清单，但要从七个视角产生真正有质量的创意，需要避开几个常见的执行陷阱。

01

**先确定一个具体的参照对象，再开始 SCAMPER。**没有具体产品或流程作为起点，七个视角都会变得空洞。「我们的 App」太模糊——「用户注册流程」或「推送通知功能」才是合适的起点。

02

**不要把 SCAMPER 当成走流程——每个视角至少花 5 分钟。**团队常犯的错误是快速「打勾」过七个字母，每个花一分钟，什么都没有真正探索。每个视角要产生至少 3–5 个想法才算真正用过这个视角。

03

**在某个视角卡住时，立刻切换到下一个，不要死磕。**SCAMPER 的设计允许你自由跳跃。「替换」视角产生不了想法，那就去「删除」——不同的人对不同视角有不同的思维优势。

04

**用不同的抽象层级应用同一个视角。**「替换」可以应用于材料、用户群体、商业模式或定价策略。在一个层级卡住，换一个层级往往豁然开朗。

05

**组合多元背景的团队，不同专业背景对同一视角的理解截然不同。**工程师看「替换」想到的是技术栈，设计师想到的是交互模式，运营想到的是渠道——多样性才能让 SCAMPER 的七个维度真正被充分探索。

06 来源与历史

从广告人的头脑风暴到七个动词改变世界的创新工具
-----------------------

SCAMPER是由鲍勃·埃伯利（Bob Eberle）于1971年正式命名的创意激发工具，其思想根源可追溯至广告创意先驱亚历克斯·奥斯本20世纪50年代提出的创意检核表。七个英文字母代表的七种操作——替换、组合、适应、修改、换用、消除、重排——构成了一套系统化激发产品创新思维的实用框架。

1953

奥斯本创意检核表提供思想基础

亚历克斯·奥斯本在《应用想象力》中列出了一份创意激发检核表，包含"能否替换？能否组合？能否适应？"等一系列提问。这份检核表为创意工作者提供了系统化突破思维定势的路径，成为SCAMPER框架最直接的思想来源。

1971

鲍勃·埃伯利将检核表提炼为SCAMPER

美国教育工作者鲍勃·埃伯利将奥斯本的检核表重新组织，提炼出七个核心操作动词，以首字母拼合成SCAMPER这一便于记忆的缩写词，并将其应用于中小学创造力教育。SCAMPER的诞生使这套方法从广告人的私人工具箱变为可被系统教授的通用创新框架。

1991

迈克尔·米哈尔科扩展推广SCAMPER

创意顾问迈克尔·米哈尔科（Michael Michalko）在畅销书《创意思考家的工具箱》（Thinkertoys）中大幅扩展了SCAMPER的应用案例与使用指南，将其从教育领域带入商业创新与产品开发的实践舞台，使SCAMPER在管理咨询与企业培训圈子中获得广泛认知。

2000年代

设计思维运动将SCAMPER带入产品圈

随着设计思维（Design Thinking）在科技公司与设计学院的普及，SCAMPER作为构思阶段（Ideation Phase）的核心工具被大量工作坊采用。产品经理开始将SCAMPER应用于功能创新、竞品差异化分析及商业模式改造等场景，展现出超越其教育起源的强大实用价值。
