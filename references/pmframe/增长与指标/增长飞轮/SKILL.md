# Growth Flywheel

Map the virtuous cycles where each step in the loop accelerates the next, creating compounding growth.

## Steps

1. Identify the **core action** users take that creates value
2. Map what that action produces as an **output** (content, data, network, etc.)
3. Trace how the output **attracts** more users or increases engagement
4. Identify what makes returning users **do more** of the core action
5. Draw the full loop and label the **force multiplier** at each connection
6. Find friction points that slow the flywheel and design interventions

## Output Format

**Flywheel Loop:**
[Action] -> [Output] -> [Attraction] -> [More Users] -> [Action] (loop)

**Force Multipliers:**
- [Connection 1]: [What amplifies it]
- [Connection 2]: [What amplifies it]

**Friction Points:** [Where the loop breaks down]
**Acceleration Plan:** [Top interventions to spin faster]

---

将产品的核心用户行为设计成自我强化的闭环：越多用户使用，产品越有价值，吸引更多用户，形成复利式增长。

## 它解决什么问题

### 线性增长迟早撞墙

大多数增长模型是线性的：投广告 → 获取用户 → 期待留存。这个模式在早期有效，但有一个致命缺陷——当广告成本上升、竞争加剧时，增长曲线会不可避免地趋于平缓。你花的每一块钱，换来的用户越来越少。

飞轮模型不同：它是自我强化的闭环，增长会产生更多增长的条件。关键问题不是「如何花钱买增长」，而是「什么机制让我们的产品越用越有价值？」

不是每个产品都有天然的飞轮，但每一个实现了可持续规模增长的产品，都找到了属于自己的飞轮。**飞轮设计的核心问题只有一个：哪一个变量，是让整个系统转速加快的关键节点？**

## 框架结构

### 两个经典飞轮，一个核心原则

飞轮由 4–6 个节点组成，每个节点的增长驱动下一个节点，最后回到起点形成闭环。识别「限速节点」（转速最慢的那一环）是飞轮优化的关键。

## 适用场景

### 什么时候该用它？

飞轮既是设计工具，也是诊断工具——用来设计增长机制，也用来找到增长停滞的根本原因。

🏗️

设计新的平台型产品

双边市场（买卖双方、创作者与消费者）天然适合飞轮设计——在产品立项时就要规划哪一边先启动飞轮。

📉

诊断增长停滞原因

当增长平台期出现，用飞轮模型找出是哪个节点断裂了——是供给侧不足，还是需求侧转化有问题？

🏰

评估产品的护城河

飞轮转速越快，壁垒越高。用飞轮分析竞争对手，判断他们的优势是否具有自我强化性，还是可以被复制的线性优势。

🕸️

规划网络效应产品

网络效应是飞轮的一种特殊形式。设计社区、通讯、市场类产品时，用飞轮模型明确「第 N 个用户如何让第 1 个用户受益」。

📊

投资人路演讲故事

飞轮图比增长曲线更有说服力——它展示了增长的内在逻辑，而不只是过去的结果。向投资人说明为什么你的增长是可持续的。

⚔️

制定对抗线性竞争者的策略

当对手依赖广告驱动增长，你的飞轮可以以指数级优势碾压他们——只要你找到并优化了真正的限速节点。

## 使用建议

### 飞轮设计的六个常见错误

飞轮模型看起来简单，但真正能驱动决策的飞轮图很难画出来。以下是最常见的陷阱。

01

**把任何圆形图都叫飞轮。**飞轮的核心是「自我强化」——每个节点必须真正驱动下一个节点增长。如果你的循环只是「做好产品 → 用户满意 → 产品变好」，这不是飞轮，是废话。

02

**节点太多（超过 6 个）。**超过 6 个节点的飞轮通常意味着你没有真正理解核心逻辑。强迫自己压缩到 4–6 个，每个节点都必须是可以被量化和优化的真实变量。

03

**不找限速节点。**飞轮画完之后，最重要的问题是：「哪个节点现在是瓶颈？」所有的资源应该集中在限速节点上，而不是均匀分布在每个节点。

04

**飞轮建在付费获客的基础上。**如果飞轮的第一个节点是「投放广告」，那它本质上还是线性增长，只是画成了圆形。真正的飞轮起点是产品内在的价值机制。

05

**不验证每个节点的因果关系。**飞轮是假说，不是事实。每一条「A → B」都需要数据验证。「更多用户 → 更多口碑」成立吗？在你的产品里，用户会主动推荐吗？先验证，再投入。

06

**飞轮只用于故事，不指导行动。**飞轮最大的价值是告诉团队「该优先投入哪里」。如果飞轮图挂在墙上却不影响任何决策，那它只是一张装饰品。每个季度的 OKR 应该能在飞轮上找到对应的节点。

## 来源与历史

### 从吉姆·柯林斯的研究到亚马逊的商业引擎

增长飞轮（Growth Flywheel）的概念最早由管理学者吉姆·柯林斯（Jim Collins）在 2001 年的《从优秀到卓越》中提出，用以描述卓越企业背后那个缓慢启动、一旦转动便自我强化的增长逻辑。亚马逊创始人杰夫·贝索斯读到这一章节后，当场在餐巾纸上画出了亚马逊的飞轮，将其升华为数字时代最著名的增长模型。

2001

柯林斯在《从优秀到卓越》中提出飞轮概念

吉姆·柯林斯经过五年对 28 家企业的对比研究，发现卓越企业的成功并非来自单一关键决策，而是多个相互强化的要素持续积累的结果——他用沉重的飞轮比喻这一过程：启动艰难，但一旦转动便越来越快。

2001

贝索斯在餐巾纸上画出亚马逊飞轮

据亚马逊高管 Brad Stone 在《一网打尽》中记载，贝索斯读完柯林斯的飞轮章节后，与同事在餐巾纸上勾勒出亚马逊的增长循环：低价→吸引流量→吸引卖家→更多商品→提升体验→更低成本→更低价格，形成经典的「亚马逊飞轮」。

2010s

增长飞轮进入产品增长方法论

随着 Airbnb、Uber、LinkedIn 等平台型公司的崛起，增长飞轮被产品增长团队（Growth Team）广泛采用，用以描述网络效应、病毒传播和用户留存之间的正反馈循环，成为产品增长策略设计的核心框架。

2019

柯林斯出版《飞轮效应》深化实践指南

柯林斯出版专著《Turning the Flywheel》，将飞轮概念从描述性分析工具升级为可操作的战略规划框架，提供了识别、构建和验证飞轮要素的系统方法，被大量企业用于战略复盘和增长模型设计。
