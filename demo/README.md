# Spec-Analyze Demo

交互式 PRD 注释展示工具。演示如何在原型/线稿上给交互组件添加结构化注释，让研发直接照着实现。

## 快速开始

```bash
# 直接用浏览器打开
open demo/index.html
```

## 功能

| 功能 | 说明 |
|------|------|
| **浮动面板** | 点击右下角 FAB 按钮打开注释面板 |
| **组件导航** | 面板顶部按钮切换不同组件（统计卡片/数据表格/创建表单） |
| **字段级注释** | 点按组件内的字段名，查看字段级别的行为/状态/样式注释 |
| **内联注释** | 行内直接显示注释标记，hover 展开详情 |
| **编辑模式** | 点击"编辑注释"进入编辑模式，支持追加/删除/撤销 |
| **验证模式** | 点击"验证"检查触发器覆盖、状态覆盖、内容规则 |

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 单页应用，所有 CSS/JS/HTML 内联（含 ANNOTATIONS 数据） |
| `screenshot-full.png` | 完整页面截图 |
| `screenshot-panel.png` | 面板打开状态截图 |

## 核心技术

- 纯 HTML/CSS/JS，无外部依赖，开箱即用
- 浮动面板交互模式（`.annot-panel` + `.annot-fab`）
- 统一状态管理（`state` 对象）
- 编辑历史与撤销（`editHistory` + `undoEdit`）
- 验证引擎（`runVerification`）
